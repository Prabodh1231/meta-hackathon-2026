Twenty elements worth copying. Each one is a pattern from the reference page, redrawn with Groundwork's own content and colours.

Tell me the numbers you want and where. Patterns like these are free to reuse; the reference site's typeface, wave artwork, logo and wording are not, so those are replaced here with system fonts, a new ribbon drawing and Groundwork's words.
