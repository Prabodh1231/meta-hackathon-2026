Write mode redesign

Three ways to present the writing tools (Nov 4). Same draft, same citations, one vocabulary (Supported, Partly supported, Not supported, No source found, Finding a source…). The buttons in each page's dark top strip step through the flows.

A · Three tasksOne panel, three jobs: Compose (Muse drafts with citations, or just chat, with your highlights on top), Check (everything that needs you, worst first), Sources (cited sources and the reference list). Versions open from the draft's name. B · On the pageNo tool panel. Muse is a command bar at the cursor (/ or Ctrl+J), problems sit in the margin beside their sentence, highlights are a badge on the paragraph. Sources and Versions are drawers. C · Write, then ReviewTwo states of the same page. Write: a quiet page plus what helps the paragraph at your cursor, with the composer docked below. Review: one checklist pass (citations, duplication, references, changes since the last version) ending in Export.

Earlier: five takes on the research companion

Same content, same docs-style writing surface (margin comments, selection toolbar, citation chips with quote popovers). Different ideas about how the library and sources should feel. 5 was picked on Oct 28.

1 · Card CatalogTopics are drawer tabs, sources are typed index cards, the source page slides out like a pulled card. 2 · BookshelfThe library is a shelf of spines sized by page count and coloured by topic. Cited sources lift off the shelf. 3 · NewsprintBroadsheet masthead, classified-ad library, evidence shown as "Exhibit A". Hard rules, no softness. 4 · Evidence BoardDark, claim-first. A wire runs from each citation to the exact highlighted quote on the source page. 5 · Focus + PaletteJust the page. Library lives behind Ctrl K, sources slide over, topics sit in a quiet dock.
