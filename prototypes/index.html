Five takes on the research companion

Same content, same docs-style writing surface (margin comments, selection toolbar, citation chips with quote popovers). Different ideas about how the library and sources should feel.

1 · Card CatalogTopics are drawer tabs, sources are typed index cards, the source page slides out like a pulled card. 2 · BookshelfThe library is a shelf of spines sized by page count and coloured by topic. Cited sources lift off the shelf. 3 · NewsprintBroadsheet masthead, classified-ad library, evidence shown as "Exhibit A". Hard rules, no softness. 4 · Evidence BoardDark, claim-first. A wire runs from each citation to the exact highlighted quote on the source page. 5 · Focus + PaletteJust the page. Library lives behind Ctrl K, sources slide over, topics sit in a quiet dock.
